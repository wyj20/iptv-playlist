**推荐（国内速度快，实测可用）：**

```
https://cdn.jsdelivr.net/gh/wyj20/iptv-playlist@main/playlist.m3u
```

## 📺 节目单（EPG）订阅

**订阅 EPG 不是订阅 m3u**——它是播放器里另一个独立设置项，填一个 XMLTV 地址。

**推荐用老张的 EPG（51zmt）**，理由是它**有 CCTV1**、山东省级频道也更全：

```
https://epg.51zmt.top:8001/e1.xml.gz
```

> ⚠️ **务必用 `https://` 这个地址（端口 8001）**。站点也有 HTTP 版（`http://epg.51zmt.top:8000/e1.xml.gz`），但 Android 9+ 默认**禁止明文 HTTP**，很多播放器会直接拉取失败。两个地址内容完全一致，都是 1,554,891 字节。
>
> 老张的 EPG 每天 **早上 7:10 更新**，数据是网络聚合来的免费节目单。含 **286 个频道 / 17,422 条节目**。

### ⚠️ 关键：必须用配套的那份播放列表

老张的 EPG 用的是**数字 id**（`1`=CCTV1，`729`=山东体育…），所以播放列表的 `tvg-id` 也得是对应的数字，否则播放器匹配不上、节目单会是空的。

| 你的 EPG 源 | 该订哪份播放列表 | 节目单覆盖 |
| --- | --- | --- |
| **老张 EPG**（推荐） | **`playlist-51zmt.m3u`** | **49 / 56** |
| 112114 或其它 | `playlist.m3u`（`tvg-id` 就是台名） | 42 / 56 |

两份文件的**流地址完全相同**，只有 `tvg-id` 不一样，随便播放器怎么选。

### 各播放器在哪里填 EPG

| 播放器 | 位置 |
| --- | --- |
| **TiviMate** | 设置 → Playlists → 你的播放列表 → EPG source 填 URL |
| **Kodi (PVR IPTV Simple)** | 插件设置 → EPG Settings → XMLTV URL |
| **电视直播 / 影视仓 / DIYP** | "EPG 接口" 或 "节目单地址" |
| **VLC** | 不支持 XMLTV 节目单 |

### 那 7 个没有节目单的频道

`山东新闻 / 山东教育卫视 / 山东居家购物 / 烟台综合 / 烟台经济 / 烟台影视 / 淄博综合`

这几个是**地市级 / 收费频道，公开渠道没有 EPG 数据源**，任何 EPG 服务都查不到，不是配置问题。它们仍然能正常播放，只是不显示节目单。

## ⚠️ 使用前必读

**1. 必须支持跟随 HTTP 302 重定向**

源站返回的是 302 跳转，它会实时生成一个带时效 token 的 CDN 地址，例如：

```
http://150.138.8.143/00/SNM/CHANNEL00000311/index.m3u8
  → 302 → http://144.123.29.177:80/wh7f454c46tw2442201345_-846757431/00/SNM/...?RTS=1791197078
```

播放器**必须自动跟随 302** 才能播放。已实测：

| 播放器 | 跟随 302 | 结果 |
| --- | --- | --- |
| VLC / PotPlayer / Kodi / mpv | ✅ | 正常 |
| TiviMate 等电视直播 App | 多数 ✅ | 正常 |
| 部分 TVBox 订阅解析 | ⚠️ 不一定 | 可能只显示频道名不播放 |

**2. 地域限制**

源站是**山东电信的 HMS CDN 集群**（`150.138.8.143`，实际回源节点为山东联通/电信 IP）。**山东省内、电信网络下最稳**；外省或海外可能加载缓慢甚至无法播放，这不是播放器的问题，无法通过换订阅地址解决。

**3. 分辨率与码率**

1080p，单频道约 **5.8 Mbps**。长时间观看注意流量消耗。

**4. 源的性质**

这些是运营商 IPTV 组播转 HTTP 的公开地址，非官方发布。**随时可能失效或变更**，尤其是运营商侧调整时。

## 播放方式

```bash
# 直接播放
mpv 'http://150.138.8.143/00/SNM/CHANNEL00000311/index.m3u8'

# 用 ffmpeg 验证流是否可用
ffmpeg -i 'http://150.138.8.143/00/SNM/CHANNEL00000311/index.m3u8' -t 5 -f null -
```
